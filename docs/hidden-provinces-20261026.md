# 隐藏街景按省份拆分 + 缺口导入 + 青海常规街景

网页版本: `v1.0.19`（2026-10-26）

## 1. 隐藏街景按省份分集合

### 之前的问题

「腾讯隐藏街景/时光机」是**一个**集合键 `hidden`，所有省份的点都挤在一起，
省份标签里只能看到一个叫「腾讯隐藏街景/时光机」的伪省份，看不到点在哪。

### 现在的做法

每个省级行政区一个键 `hidden_<省码>`（`hidden_37` 山东、`hidden_34` 安徽、`hidden_65` 新疆…），
`PANO_META[key].province` 写真实省份，查看器里直接跟在对应省份标签下。

省份归属是**数据驱动**的：把全部城市图层的点按 0.2° 网格分桶，每个格子统计各省点数；
隐藏点取所在格子的多数省，空格子向外扩到 2 环（约 60 km）。最终：

| 项 | 数值 |
|---|---|
| 隐藏集合键 | 31 个（30 个省级行政区 + 1 个兜底 `hidden`） |
| 可归属 | 24,519 |
| 未归属（落在 `hidden`） | **2,356**（偏远景区、周边无城市扫描数据） |
| 合计 | 26,875（拆分前原值，未增减） |

查看器侧改动：`hidden` 判定从「等于 `hidden`」改为「`pref` 以 `hidden` 开头」（`isHiddenPref`），
`tools/build_viewer_index.js` 与 `tools/check_viewer_hidden_grid.js` 也改成遍历所有 `hidden*` 键。

## 6. 校验

- 拆分前后隐藏点总数一致（26,875），无坐标越界（国境框 73–136E / 3–54N）。
- 每个隐藏键的 `PANO_COUNT` 与文件条数、网格计数三者相等，`check_viewer_hidden_grid.js` 全量校验通过。
- 缺口导入去重：826 条已存在于城市图层，2 条已存在于隐藏集合。
- 青海导入：306,710 条，0 重复、0 非法坐标；`data_meta.js` 计数与 6 个文件条数一致。
- `check_viewer_display_mode.js` 通过。

## 7. 仍未解决

- **2,356 条隐藏点无法归属省份**，只能留在 `hidden` 兜底下（多为无人区/边境景区）。
- 省份归属是**网格多数投票的近似**，省界附近（尤其 0.2° 格子跨省）可能有个别误判；要看精确定位还需引入省级行政边界做点在面内判断。
