# 浙江全省 + 十市补扫导入

网页版本: `v2.2.0`（2026-10-29）

本批两件事：浙江全省区县包合入查看器，以及 8 份缺口扫描结果（10 个地级市）的移动性审计与分流。
APK 同步产出，`versionCode 17` / `versionName 2.2.0`。

## 6. 校验

- `tools/check_viewer_hidden_grid.js`：137 个隐藏集合 / 102,067 点 / 39,735 格，逐集合条数、网格、计数三者一致；
- `tools/check_viewer_display_mode.js`：PASS；
- `build_viewer_index.js` 统计 `entries=21,670,521`，与 `PANO_COUNT` 合计相等；
- 本批 10,745 个 sid 在查看器中**各出现 1 次**（缺失 0、重复 0）；
- 浙江 36 个分片的文件条数与 `PANO_COUNT` 逐一相等（`bad: []`）。

## 7. 已知边界（诚实说明）

- 浙江包是区县粒度，与原仓库的市级分片做的是**并集**；若包内某区县是残缺瓦片，旧点仍在，不会因此减少。
- 包内 `data_meta.js` 是福建模板残留，本文档与导入流程都没有采信它；区县名没有进仓库（只聚合到市级）。
- 大兴安岭 3 条隐藏点单独成集，样本很少，不代表该地区隐藏街景总量。
- 十市审计仍是服务端视角（元数据邻接），元数据缺邻接但客户端可移动的极端情况识别不了。
- 审计过程中直连地址被网关限流两次（各约 1,400 次后返回 500），脚本已改为**按出口熔断 + 双出口分流**，
  失败记录以 `error` 落盘并在续跑时重试，本批最终 `error = 0`。
