# 隐藏街景按地级市选择 + 五个城市缺口导入

网页版本: `v1.0.20`（2026-10-26）

## 1. 需求与实现

要求：隐藏街景支持「先选省、再选地级市」两个下拉。

改动：

- 顶部原来的**省份标签页**换成 `<select id="provinceSelect">` 下拉，与右边已有的城市下拉组成两级。
- 未选省份（停在「全国」）时，城市下拉**禁用**并显示「请先选择省份」；选定省份后自动启用，只列出该省有数据的城市。
- 隐藏集合从「一省一集」改为「**一地级市一集**」：`hidden_371300`（临沂）、`hidden_340200`（芜湖）…
  下拉里显示为「临沂市·隐藏街景」，与同市的常规数据并列，互不干扰。

## 2. 边界数据

来源：**DataV GeoAtlas**（`geo.datav.aliyun.com/areas_v3/bound/`），34 个省级单位 → **367 个地级行政区**多边形。

为什么不用 OSM：OSM 的行政边界把**藏南**划在印度阿鲁纳恰尔邦，直接套用会把藏南的点判到境外或丢弃；
DataV 按中国官方口径，藏南落在**林芝市/西藏自治区**。实测：

| 检验点 | 坐标 | 判定结果 |
|---|---|---|
| 达旺（藏南） | 94.50E, 28.50N | 林芝市 / 西藏自治区 ✅ |
| 三沙海域岛屿 | 112.30E, 16.80N | 三沙市 / 海南省（海域空白处不命中，属正常，多边形是岛不是海） |
| 天安门 | 116.40E, 39.90N | 北京市 ✅ |

南海诸岛在数据里是独立要素 `100000_JD`（九段线示意），**不作为行政区参与归属**；岛礁由海南省**三沙市 460300** 覆盖。

## 3. 坐标系

街景坐标与 DataV 边界**同为 GCJ-02**，实测无需转换：

- 取上海 20,000 个点做自洽检验：落在上海多边形内 **99.725%**，其余 55 个点都在嘉善/嘉兴边界，属正常边界歧义。
- 对照实验：给这些点加 ±0.0055°/±0.0015°、+0.01°/+0.004° 偏移后，自洽率**没有提升**（99.49% / 99.74% / 99.49%）。
  若两边基准不同，加偏移应显著改善——没有改善说明本来就同基准。
- 结论：**不做 GCJ-02 ↔ WGS84 转换**，否则反而引入 500 m 级误差。

## 7. 校验

- `check_viewer_hidden_grid.js`：107 个隐藏集合、61,760 点、23,477 网格格，逐集合的条数/网格/计数三者一致。
- `check_viewer_display_mode.js` 通过；内联脚本 `node --check` 语法通过。
- 审计 10,874 / 10,874，`invalid`、`error` 均为 0。

## 8. 未解决

- **26 条隐藏点不在任何地级边界内**（海上、边境界线外或坐标异常），只能留在兜底 `hidden`。
- 边界数据只到**地级**：县级筛选仍依赖 `data_districts.js`（只有 81 个地级市有区县多边形），其余城市不显示区县下拉。
- 省界/市界附近仍有个别点会判到邻市（上海实测 0.275%），对展示影响很小，但不适合做严格统计。

## 9. 补充：香港、三沙、剑灵（v1.0.21）

首版按地级拆分时这三类落到了兜底集合，已修正：

| 类型 | 原因 | 处理 | 结果 |
|---|---|---|---|
| 香港 | 拆分时跳过了港澳边界（`SKIP` 里有 810000），5 条点位无多边形可判 | 港澳按「省级=地级」单列（同直辖市），补入 810000/820000 边界 | `hidden_810000` 香港特别行政区·隐藏街景 **5** 条 |
| 三沙 | 三沙的多边形是**岛礁**，海面上的点位落在多边形外 | 加「最近边界」兜底：不在任何多边形内时，取 120 km 内最近的行政区 | `hidden_460300` 三沙市·隐藏街景 **4** 条（三沙市政府、西沙海洋博物馆、西沙宾馆、老龙头） |
| 剑灵 | 15 条点位坐标是**虚构的**（111.62E / 10.30N，南海海面），地理上无法归属 | 单列集合 `hidden_game`，来源判定见 `tools/data/tencent-game-exceptions.json` 或路名含「剑灵」 | `hidden_game` 剑灵游戏街景 **15** 条（独立「腾讯游戏街景」分组） |

最近边界兜底还顺带修正了鸭绿江边的 2 条：归入**丹东市**（`hidden_210600` 共 3 条）。

结果：兜底 `hidden` 从 **26 → 0**，隐藏集合 **112 个**（111 个地级 + 1 个剑灵），总点数不变（61,760）。
