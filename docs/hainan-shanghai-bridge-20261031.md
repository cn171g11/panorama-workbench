# 海南全省扫描 + 上海长江隧桥补扫

网页版本: `v2.4.0`（2026-10-31）

> **更正**：本文档的海南部分（117,553 点）后来被证实漏采 85%，已用官方扫描器重扫并取并集，结果为 493,309 点。差异原因与补救过程见 `docs/hainan-rescan-20261031.md`。

## 一、海南

### 1. 方法

沿用 `tools/scan_boundary_streetview.mjs`：边界内网格播种 → `/xf` 找种子 → `/sv` 的 `all_scenes` 序列展开。
与香港不同的是**播种间距**：

| 项 | 香港 | 海南 | 原因 |
|---|---|---|---|
| 播种间距 | 0.004°（约 440 m） | **0.01°（约 1.1 km）** | 海南岛 33,900 km²，440 m 网格要铺 17.8 万格、约 4 小时；1.1 km 为 3.2 万格 |
| 播种格 | 7,075 | 31,924 | |
| 种子 | 2,691 | **1,174** | |
| 采集 | 374,429 | **117,553** | |

**三沙市（460300）不参与**：其边界横跨 109.46–117.84 E / 3.84–19.53 N，会把播种网格撑到 8°×14°。
实测永兴岛、西沙、南沙三处 `/xf`（r=2000）均无街景，排除是合理的。

### 3. 覆盖密度（诚实说明）

1.1 km 播种间距意味着：**两条种子之间的小路，如果自身没有序列被别的种子覆盖，就会漏掉**。
城市与干道覆盖完整（海口 4.1 万、三亚 3.8 万），乡村支路可能有缺口。
若要补齐，需要在目标区域用 0.004° 再播一轮（约 4 小时 / 17.8 万次请求），本次没有做。

## 二、上海长江隧桥补扫

### 1. 问题定位

不是"整段没有数据"，而是**沪陕高速在长兴岛—崇明之间断了 6,255 m**：
从 (121.7305, 31.4101) 到 (121.7671, 31.4569) 之间没有任何点位。

### 2. 补扫

用两个矩形走廊构成临时边界（`121.715–121.805 × 31.395–31.475` 覆盖大桥，
`121.715–121.815 × 31.325–31.400` 覆盖隧道走廊），播种 912 格 → 67 个种子 → **2,021 点**。

导入用新增的 `--append` 模式：只查新 sid 是否已存在，把新点追加到末尾分片 `310000_26`，
不重写另外 25 个分片（390 万点）。**新增 627 点**，1,394 点已存在。

| 项 | 补扫前 | 补扫后 |
|---|---|---|
| 桥轴 300 m 内点位 | 66 | **693**（新增 627 全部落在桥轴上） |
| 桥轴最大相邻间距 | 6,255 m | **191 m** |
| 上海分片 `310000_26` | 16,692 | 17,319 |

### 3. 隧道为什么补不了

沿隧道轴线（121.72–121.82 E / 31.33–31.38 N）逐点 `/xf` 探测（r=600）全部无返回，
说明腾讯没有在水下隧道内采集街景。扫描到的 358 个隧道走廊点全部位于**长兴岛一侧入口**
（纬度 31.3793–31.4049），即隧道口以北。这一段无可补数据。
