## 4. 一次返工：跨集合重复

首轮导入后有 **22 个 sid 同时存在于城市图层与新集合**——因为当时的查重只做了"目标集合内"，
而这 22 个点原本就在 `data_5101xx.js` 等城市图层里。这违反"按 sid 全局查重"的红线。

处理：回滚 `city-viewer`，先扫这四个省的城市图层与 `hidden_pano.js` 建排除表（22 个 sid），
再带 `--existing` 重新导入。复核结果：9,755 个 sid **各出现 1 次**（缺失 0、重复 0）。

工具已把这条写进参数：`import_map_export.py --existing <json>`。
