## 3. 两处修正

1. **74 个跨市重复**：合并只保证"目标集合内"唯一，而这 74 个 sid 旧数据存在相邻市
   （黄石/鄂州 46、武汉/黄冈 26、黄石/黄冈 1、咸宁/黄冈 1）。按"包内区县归属优先"删除副本，
   复核后 2,281,746 个源 sid **全库各出现 1 次**。
2. **`429000` 原名「潜江市」**：它装的是仙桃、潜江、天门、神农架四个省直辖县级单位，
   改名为「省直辖县级行政区划」，与海南 `469000` 的处理一致。

- `check_viewer_hidden_grid`：145 集合 / 108,018 点 / 42,714 格，三者一致；
- `check_viewer_display_mode`：PASS；
- `build_viewer_index`：`entries=24,799,870`，与 `PANO_COUNT` 相等；
- 湖北 2,281,746 个源 sid 全部入库，**缺失 0、重复 0**。

- 恩施州只有 1 个区县文件（恩施市 907 点），其余 7 县不在包里，属于数据源本身的覆盖范围。
