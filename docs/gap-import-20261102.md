## 3. 采集时间全量回填

用户报告详情页采集时间为空。排查：详情代码一直在渲染（空值显示"—"），空的是**数据**——
浙江/广西/四川/西藏/云南等区县包批次与地图导出批次源数据不含 `captured`。

关键发现：**腾讯 svid 第 9–14 位（`sid[8:14]`）内嵌采集日期 20YYMMDD**：
- 290,926 条已填样本（南京/广州/北京/长沙）与 `captured` 日期 **100% 吻合**；
- 德州缺口扫描 `gapId` 中的日期与 svid 推导 **500/500 吻合**。

据此全库回填：**21,502,779 点**补上采集日期（格式 `YYYY-MM-DD`，仅日期无时刻），
剩余 31,945 点（1.1%，`270130K...SCENE001` 类字母开头游戏 id 与不规则短 id）保持为空。
详情面板与按采集时间搜索即时生效。

## 6. 过程记录

- 审计任务首次启动因输出目录不存在立即失败（0 请求发出，无配额浪费），建目录后重跑。
- 导入 dry-run 超 40 分钟未完成：全库排除表（2,896 万条）构建期间 Python 分代 GC 反复扫描巨型对象图
  是主要开销。`gc.disable()` 包装后完整导入 **约 8 分钟**完成（lessons #65）。
- 12 省 `country.json`/`<6位码>.json` 边界由 DataV 现取（齐齐哈尔批次跨内蒙古、信阳批次跨湖北，
  省列表必须覆盖边界省，否则点落 `no_prefecture`）。
