```text

heading     原始朝向（度）
pitch/zoom  原始视角参数，保留未用
tags        导出时的标签（export / exported_selection_* 等）
source      固定 baidu_pano
```

## 为什么单独放

1. 百度与腾讯的 id 体系、坐标系、可移动性判定完全不同，混在一个集合里无法复用现有审计工具。
2. 查看器的「腾讯隐藏街景/时光机」合集只接受腾讯 `svid`（`tools/pano-mobility.js` 的判定依赖腾讯元数据接口）。
3. 用户明确要求：百度数据先挑出来放着，等后续有具体计划再处理。

经纬度范围：75.183479–94.695464 E，37.055352–48.516432 N（覆盖新疆全境）。
