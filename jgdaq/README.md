# 加格达奇区腾讯街景扫描数据

- 扫描方式：从市中心种子出发，沿 `all_scenes` 相邻采集点 BFS 爬行，区界多边形实时过滤
- 数据源：腾讯街景非官方接口（`sv.map.qq.com/sv`、`sv1.map.qq.com/thumb|tile`），GBK 解码
- 坐标过滤：阿里 DataV GeoAtlas `232718.json`

## 完整性核查结论

曾因"边界内网格占用率仅 9.9%"判定为严重漏扫，经全域网格探测
（1693 个探测点，0.01° 间距）复核后**推翻了该结论**：

- 探测命中 122 个网格，全部落在已有数据 **0.9 公里以内**
- 其余约 90% 的边界内区域为林区与农垦区，腾讯本就没有采集
- 结论：**加格达奇区无漏扫，现有数据即完整覆盖**

## 文件

- `jgdaq-panoramas.json`：全量清单（panoid/坐标/朝向/道路/采集时间/缩略图/全景标记）
- `jgdaq-panoids.json|.txt`：纯 panoid 列表
- `jgdaq-boundary.geojson`：加格达奇区边界（adcode 232718）
- `raw/_inside.json`：完整点位数据
- `raw/_gap_seeds.json`：完整性核查用的探测种子
