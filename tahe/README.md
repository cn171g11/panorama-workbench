# 塔河县腾讯街景扫描数据

- 扫描方式：从县城中心种子出发，沿 `all_scenes` 相邻采集点 BFS 爬行，塔河县界多边形实时过滤
- 数据源：腾讯街景非官方接口（`sv.map.qq.com/sv`、`sv1.map.qq.com/thumb|tile`），GBK 解码
- 坐标过滤：阿里 DataV GeoAtlas `232722.json`

## 重要说明：数据已补扫

首轮种子 BFS 只覆盖了县城周边（lng 124.68~124.74）。经全域网格探测
（18615 个探测点，0.01° 间距）发现县境内西南部 **123.54~123.70, 52.69~52.78**
存在独立街景覆盖区，距原数据区约 90 公里，此前完全未扫到。

已用探测出的 223 个连通分量种子重新 BFS，补充 **5059 个点**，数据范围随之
从 0.4% 扩大到覆盖县城 + 西南林区两片区域。全景下载因触发腾讯接口限流
（HTTP 500）中断，剩余 1332 张待补。

## 文件

- `tahe-panoramas.json`：全量清单（panoid/坐标/朝向/道路/采集时间/缩略图/全景标记）
- `tahe-panoids.json|.txt`：纯 panoid 列表
- `tahe-boundary.geojson`：塔河县边界（adcode 232722）
- `raw/_inside.json`：完整点位数据
- `raw/_gap_seeds.json`：补扫探测得到的 223 个种子
- `raw/_pano_sample_ids.json`：80m 采样全景目标（2796，1464 已完成）
