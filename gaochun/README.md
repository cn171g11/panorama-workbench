## 扫描方法

采用与溧水一致的两级网格穷举，而非单种子 BFS：

1. **粗网格 1 km**：930 格，探测半径 500 m → **57 格有覆盖**（6.1%）
2. **细网格 200 m**：在已覆盖格的邻域内探测 2266 点 → **1291 个种子**
3. **BFS 展开**：沿 `all_scenes` 相邻采集点扩散，区界多边形实时过滤 → **37128 点**
4. **缺口审计**：800 m 网格全域 1170 点探测，105 格命中 → **新增 0**

## 完备性说明

第 4 步的审计探测结果为 `NEW_SVIDS=0`，即全域探测到的所有街景均已包含在 BFS 结果中，
**不存在漏扫**。边界内东北部大片空白区域为真实的无覆盖区（乡村、水域、山地）。

这一点与塔河县的情况不同：塔河首轮仅从县城种子做 BFS，遗漏了距县城 90 公里的
独立覆盖区（补扫后新增 5059 点）。高淳的审计证明其街景为单一连通路网，BFS 已完整覆盖。
